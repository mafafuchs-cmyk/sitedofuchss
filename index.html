Estruturação

HTML5

Construção de páginas semânticas, organizadas e acessíveis para usuários e motores de busca.

Uso para estruturar páginas web com marcação semântica, hierarquia clara de conteúdo e boas práticas de acessibilidade — garantindo que o site seja compreensível por usuários e motores de busca.

Estilização

CSS3

Criação de layouts responsivos, modernos e atraentes com foco na experiência visual em qualquer dispositivo.

Utilizo Flexbox e Grid para construir layouts adaptáveis a qualquer tela, além de variáveis CSS, animações e transições para criar interfaces com identidade visual coesa e interações fluidas.

Interatividade

JavaScript

Implementação de comportamentos dinâmicos, manipulação do DOM e soluções lógicas para o navegador.

Aplico JavaScript para manipular o DOM, responder a eventos do usuário, criar animações baseadas em scroll e tornar as páginas interativas sem depender de bibliotecas externas.

Design de Interface

Figma

Planejamento e prototipagem de interfaces intuitivas, alinhando visual e usabilidade antes do código.

Crio wireframes e protótipos interativos no Figma antes de escrever qualquer linha de código, definindo paleta de cores, tipografia e fluxo de navegação para garantir um resultado visual consistente.

Criação Gráfica

Adobe Express

Produção rápida de peças gráficas, banners e elementos visuais para apoiar a identidade dos projetos.

Uso para criar rapidamente capas, banners e materiais gráficos que reforçam a identidade visual de cada projeto, mantendo consistência entre o design digital e as peças de comunicação.

Edição de Vídeo
